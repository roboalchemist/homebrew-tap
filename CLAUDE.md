# homebrew-tap

Public Homebrew tap for `roboalchemist` tools, hosted at `github.com/roboalchemist/homebrew-tap`.

## Install

```bash
brew tap roboalchemist/tap
brew install <formula>
```

## Formula Patterns

### Go (GoReleaser) — Binary Distribution

GoReleaser auto-generates these. Formula is tagged `# This file was generated by GoReleaser. DO NOT EDIT.`

```ruby
class ExaCli < Formula
  version "0.1.3"

  on_macos do
    if Hardware::CPU.intel?
      url "...darwin_amd64.tar.gz"
      sha256 "..."
      def install = bin.install "exa"
    end
    if Hardware::CPU.arm?
      url "...darwin_arm64.tar.gz"
      sha256 "..."
      def install = bin.install "exa"
    end
  end

  on_linux do
    # amd64 + arm64 variants
  end
end
```

### Go (Source Build)

```ruby
depends_on "go" => :build

def install
  system "go", "build", *std_go_args(ldflags: "-s -w -X .../cmd.version=#{version}")
end
```

### Python (pip + wrapper script)

Standard pattern: install deps to `libexec/vendor`, install source to `libexec`, write a bash wrapper:

```ruby
depends_on "python@3.12"

def install
  system Formula["python@3.12"].opt_bin/"pip3.12", "install",
         "--target=#{libexec}/vendor",
         "click>=8.1.0", "httpx>=0.27.0", ...

  libexec.install Dir["*"]   # or specific files

  (bin/"toolname").write <<~EOS
    #!/bin/bash
    export PYTHONPATH="#{libexec}/vendor:#{libexec}:$PYTHONPATH"
    exec "#{Formula["python@3.12"].opt_bin/python3.12}" -m toolname.cli "$@"
  EOS
end
```

### Python (uv-based)

Used by `any2md` for faster resolution:

```ruby
depends_on "python@3.12"
depends_on "uv"

def install
  python = Formula["python@3.12"].opt_bin/"python3.12"
  uv = Formula["uv"].opt_bin/"uv"

  system uv, "pip", "install", "--python=#{python}", "--target=#{libexec}/vendor", ...
end
```

## Adding a New Formula

1. Create `Formula/<name>.rb` — use the appropriate pattern above
2. Set `url` to a GitHub release tarball (with `sha256`)
3. Write a `test do` block — minimum: `assert_match "toolname", shell_output("#{bin}/toolname --help 2>&1")`
4. Commit and push to `main`

```bash
# Compute sha256 for a tarball
curl -sL <url> | sha256sum
# or on macOS:
curl -sL <url> | shasum -a 256
```

## Bumping a Formula Version

1. Update `url` to new release tag
2. Update `sha256` to match new tarball
3. Update `version` field (GoReleaser formulas only)
4. Commit: `git commit -m "<formula>: bump to v<version>"`

Use the `brew-bump` skill or `managing-github` skill to automate this.

## Testing

```bash
# Install from local tap
brew install --build-from-source ./Formula/<name>.rb

# Test formula
brew test <name>

# Audit formula
brew audit --strict ./Formula/<name>.rb
```
